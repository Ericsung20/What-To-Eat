# 🍽️ What-To-Eat

A full-stack campus dining recommendation app that helps UW-Madison students decide what to eat based on dining hall menus, personal preferences, and nutrition goals.

What-To-Eat was developed by the 2026 Spring CS Mini Team as a real-world full-stack project focused on frontend-backend integration, API design, database planning, and team collaboration.

---

## 🎯 The Problem

Many students often struggle with deciding what to eat at campus dining halls.

Dining hall menus may include many options, but students still need to consider:

* Personal food preferences
* Diet goals such as cutting or bulking
* Calories and nutrition information
* Allergies or dietary restrictions
* Dining hall location and menu availability

What-To-Eat aims to make this decision easier by organizing dining hall data and recommending better meal options for each user.

---

## ✨ Features

* 🔐 User login and sign-up
* 🧾 Dining hall menu display
* 🍱 Meal recommendation based on user preferences
* 📊 Nutrition information such as calories and macronutrients
* ⭐ Favorite or saved food options
* 👤 User profile and preference settings
* 🔎 Food filtering by user needs
* 🔗 Frontend and backend API integration

---

## 🕹️ How It Works

1. Users log in or create an account
2. The app loads dining hall menu data
3. Users set preferences such as diet goals, allergies, or food choices
4. The backend processes food and user data
5. The frontend displays recommended meal options in a clean interface

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Ericsung20/What-To-Eat.git
```

### 2. Run the frontend

```bash
cd WhatToEat-Frontend
npm install
npm run dev
```

### 3. Run the backend

```bash
cd WhatToEat-Backend
pip install -r requirements.txt
uvicorn main:app --reload
```
