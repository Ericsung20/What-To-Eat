# \# 🍽️ What-To-Eat

# 

# A full-stack campus dining recommendation app that helps UW-Madison students decide what to eat based on dining hall menus, personal preferences, and nutrition goals.

# 

# What-To-Eat was developed by the 2026 Spring CS Mini Team as a real-world full-stack project focused on frontend-backend integration, API design, database planning, and team collaboration.

# 

# \---

# 

# \## 🎯 The Problem

# 

# Many students struggle with deciding what to eat at campus dining halls.

# Dining hall menus have many options, but students still need to think about preferences, calories, nutrition, allergies, and dining hall location.

# 

# What-To-Eat helps users make better meal choices by organizing dining hall menu data and recommending food options based on user needs.

# 

# \---

# 

# \## ✨ Features

# 

# \* User login and sign-up

# \* Forgot password page

# \* Dining hall menu display

# \* Meal recommendation based on user preferences

# \* Nutrition information such as calories and macronutrients

# \* User profile and preference settings

# \* Food filtering by user needs

# \* Frontend and backend API integration
